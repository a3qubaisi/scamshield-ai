# ML training

- `gen_uae.py`: generates `data/uae_synth.tsv`, a synthetic Arabic/English UAE scam and legitimate SMS corpus (template-based, seeded so it is reproducible).
- `train.py [K]`: trains the char n-gram logistic regression on UCI + synthetic data, prints the held-out metrics, and writes `model.json` and `parity.json`.
- `export_model.py`: copies the model into the app.

After training, refresh the app:
```bash
python3 ml/export_model.py      # writes src/model.js and tests/parity.json
python3 build.py                # rebuilds dist/scamshield.html
node tests/engine.test.js       # must print 41/41 passed
```

## Data
- `data/sms.tsv`: the UCI SMS Spam Collection, T. A. Almeida & J. M. Gómez Hidalgo (2011), "Contributions to the Study of SMS Spam Filtering". It comes from the UCI Machine Learning Repository and is licensed CC BY 4.0.
- `data/uae_synth.tsv`: synthetic data generated by `gen_uae.py`. It contains no real personal data. All phone numbers are fake (all zeros), and the domains are invented examples.
